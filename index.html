Виджет на рабочий стол

Виджет с температурой и кнопками 1 / 0 — в нашем маленьком приложении:

  1. Скачать kotel.apk
  2. Откройте скачанный файл → разрешите установку из этого источника → Установить.
  3. Откройте «Котёл», войдите → Добавить виджет на рабочий стол.
Другой способ — через приложение HTTP Shortcuts
  1. Установите HTTP Shortcuts из Google Play / RuStore / F-Droid.
  2. В нём: ⋮ → Variables → + → тип Static. Создайте 4 переменные: oc_login (email), oc_password (пароль), kotel и kotel_cache (пустые).
  3. + → Scripting → имя «Котёл обновить» → вставьте код:
  4. Так же сделайте ярлыки «RESET 1» и «RESET 0»:
  5. Запустите «Котёл обновить» один раз.
  6. Рабочий стол → долгое нажатие → Виджеты → HTTP Shortcuts: виджет Variable (переменная kotel, по нажатию — «Котёл обновить») и два виджета-ярлыка RESET 1 / RESET 0.

Быстрый вариант без приложений: долгое нажатие на иконку «Котёл» → ярлыки RESET 1 / RESET 0 можно перетащить на рабочий стол.

  1. Установите бесплатное приложение Scriptable из App Store.
  2. Скопируйте код:
  3. В Scriptable: + → вставьте код → назовите Kotel → запустите ▶ и войдите.
  4. Рабочий стол → долгое нажатие → + → Scriptable → средний размер → нажмите на виджет → Script: Kotel.
