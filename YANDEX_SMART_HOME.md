# Умный дом Яндекса в Android-приложении

Плашка **Умный дом Яндекса** открывает отдельный экран подключения и устройств. Она доступна с главного экрана и со страницы входа в OwenCloud. В Android-приложении у каждого сервиса свой вход.

Одну и ту же сборку можно установить на два телефона. Каждый человек входит под своим Яндекс ID и видит устройства, доступные этому аккаунту. На одном телефоне можно выйти из Яндекса в приложении и подключить другой аккаунт.

## 1. Добавьте датчики в «Дом с Алисой»

1. Войдите в **Дом с Алисой** под своим Яндекс ID.
2. Добавьте устройства по инструкции для вашей модели. Для датчиков протечки и климата Яндекса с Zigbee понадобится совместимый хаб Яндекса. В приложении выберите **+ → Устройство умного дома → Поиск Zigbee** и переведите датчик в режим подключения. [Датчик протечки](https://alice.yandex.ru/support/ru/leak-sensor/turn-on/app), [датчик температуры и влажности](https://alice.yandex.ru/support/ru/climate-sensor/turn-on/app)
3. Откройте карточки датчиков в «Доме с Алисой» и проверьте, что они передают показания. При желании присвойте им имена и выберите комнаты. Эти имена и комнаты появятся в APK после загрузки.

## 2. Один раз настройте Яндекс OAuth для сборки

1. Войдите в кабинет Яндекс OAuth под аккаунтом разработчика и начните регистрацию приложения **Для авторизации пользователей**. Если для испытаний уже создавали приложение типа **Для доступа к API или отладки**, для нескольких пользователей создайте новое. [Создание приложения в Яндекс OAuth](https://oauth.yandex.ru/client/new/id/) · [Типы приложений](https://yandex.ru/dev/id/doc/ru/register-client)
2. Укажите название, иконку и контактную почту. Выберите платформу **Веб-сервисы**, поскольку на этом шаге настраивается браузерный вход с кодом. В поле **Redirect URI** вставьте `https://oauth.yandex.ru/verification_code`. [Регистрация приложения для авторизации](https://yandex.ru/dev/id/doc/ru/register-auth) · [Вход с кодом подтверждения](https://yandex.ru/dev/id/doc/ru/codes/screen-code)
3. В разделе **Доступ к данным** добавьте `iot:view` (**Просмотр списка устройств умного дома**) и `iot:control` (**Управление устройствами умного дома**). Сохраните приложение и скопируйте его **Client ID**. [Права доступа к API умного дома](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-protocol)

APK пользуется OAuth с PKCE и подключается к API напрямую с телефона. В сборку передаётся только **Client ID** приложения. После входа токен конкретного пользователя хранится на его телефоне.

## 3. Соберите APK

Добавьте строку в `android-app/local.properties`, сохранив существующую строку `sdk.dir`. Подставьте свой Client ID вместо примера.

```properties
yandex.clientId=ВАШ_CLIENT_ID
```

`local.properties` уже исключён из Git. Для сборки из терминала можно также передать переменную окружения `YANDEX_CLIENT_ID`. Когда она задана, Gradle берёт её значение в первую очередь.

Для локальной сборки откройте `android-app/` в Android Studio. Установите JDK 17 и Android SDK Platform 36, затем соберите release через Gradle. Из корня репозитория на macOS или Linux:

```bash
cd android-app
./gradlew :app:assembleRelease
```

На Windows используйте `gradlew.bat :app:assembleRelease`. Подписанный APK появится в `android-app/app/build/outputs/apk/release/app-release.apk`.

Для GitHub Actions добавьте переменную репозитория `YANDEX_CLIENT_ID` в **Settings → Secrets and variables → Actions → Variables**. После загрузки изменений запустите workflow **Android APK** во вкладке **Actions**. При изменении `android-app/` в `main` сборка запускается автоматически и прикладывает `kotel.apk` к релизу.

Сборка без Client ID показывает на экране Яндекса сообщение о том, что вход ещё не настроен. Для обновления уже установленной версии из GitHub Releases используйте APK из более свежего запуска workflow. Локальная сборка по умолчанию имеет `versionCode=1`, поэтому Android может отклонить её как более старую.

## 4. Войдите в Яндекс в APK

1. Установите настроенный APK, откройте плашку **Умный дом Яндекса** и нажмите **Войти через Яндекс**.
2. В браузере выберите свой Яндекс ID, предоставьте доступ и скопируйте код. Если код виден в адресе страницы после `code=`, можно скопировать весь адрес. Для переключения розетки разрешите **Управление устройствами умного дома**. Пользователи, которым нужен только просмотр, могут пропустить это разрешение.
3. Вернитесь в приложение, вставьте код или адрес страницы Яндекса и нажмите **Подключить**. Используйте код в течение 10 минут. [Подтверждение входа по коду](https://yandex.ru/dev/id/doc/ru/codes/screen-code) · [Код в адресе страницы](https://yandex.ru/dev/id/doc/ru/codes/code-url)
4. Проверьте, что появились устройства выбранного аккаунта. Для проверки на втором телефоне установите тот же APK и войдите под другим Яндекс ID. На одном телефоне для смены аккаунта нажмите **Отключить аккаунт**, затем **Войти через Яндекс** и выберите другой аккаунт в браузере.

## Проверка управления на розетке

1. Убедитесь, что розетка уже добавлена в «Дом с Алисой» и отвечает на команды. Для испытания можно оставить розетку без подключённого прибора. [Подключение Wi-Fi-розетки YNDX-0007](https://alice.yandex.ru/support/ru/socket/turn-on)
2. В APK откройте **Умный дом Яндекса**. Если входили в предыдущей версии или пропустили запрос на управление, нажмите **Отключить аккаунт** и войдите заново с разрешением на управление.
3. В карточке розетки нажмите **Включить** и подтвердите команду. После успешного ответа Яндекса APK запросит показания. Сверьте **Питание · Включено** со статусом в «Доме с Алисой». Повторите проверку кнопкой **Выключить**.
4. Если результат команды неизвестен, нажмите **Обновить показания**, чтобы проверить текущее состояние. Кнопки управления появляются у устройств, которые передают возможность включения и выключения. [Управление умениями устройств](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-capabilities)

## Показания и повторное подключение

- Датчик протечки показывает **Сухо**, **Обнаружена протечка** или **Нет данных** в зависимости от показания Яндекса.
- Для устройств отображаются температура, влажность, заряд и состояние включения, если Яндекс отдал эти свойства. При наличии времени измерения оно отображается под показанием.
- APK запрашивает последние данные из облака при входе на экран, по кнопке и примерно каждые 30 секунд, пока экран открыт. Фактическая частота измерений зависит от датчика. Уведомления о протечках можно настроить в «Доме с Алисой». [Уведомления датчика протечки](https://alice.yandex.ru/support/ru/leak-sensor/how-use)
- Если список пуст, проверьте аккаунт и наличие устройств в «Доме с Алисой». Если Яндекс отказал в доступе, проверьте `iot:view` и получите новый код. После истечения или отзыва токена войдите заново.
- **Отключить аккаунт** удаляет сохранённое подключение с телефона. Для отзыва разрешения у Яндекса откройте раздел **Доступы к данным** в Яндекс ID. [Отзыв OAuth-токена](https://yandex.ru/dev/id/doc/ru/tokens/token-invalidate)
