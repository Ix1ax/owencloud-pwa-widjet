# Котёл — виджет OwenCloud

Мини-приложение для телефона: показывает текущую температуру (Temp_E, P512) и даёт записать Reset_E (P527) = 1 или 0.

- **Без бэкенда.** Это статический сайт: страница обращается прямо к `https://api.owencloud.ru` (API разрешает такие запросы).
- **Логин и пароль** вводятся на телефоне и хранятся только на нём (память браузера / Keychain в Scriptable). В репозитории их нет.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html`, `style.css`, `app.js` | само приложение (вход, температура, кнопки RESET) |
| `manifest.webmanifest`, `sw.js`, `icons/` | чтобы сайт ставился на рабочий стол как приложение |
| `scriptable/Kotel.js` | настоящий виджет для iPhone через приложение Scriptable |

## 1. Выложить на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `owencloud-widjet`, и загрузите туда все файлы из этой папки (кроме `.claude/`).
2. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/owencloud-widjet/`.

## 2. Первый вход

1. Откройте адрес сайта на телефоне.
2. Введите email и пароль OwenCloud, нажмите **Войти**.
3. Приложение само найдёт прибор и параметры `Temp_E (P512)` и `Reset_E (P527)`. Если нужно, выберите другие в списках.
4. Нажмите **Сохранить**. Дальше откроется главный экран с температурой.

Когда токен OwenCloud истекает, приложение тихо входит заново сохранённым паролем.
Кнопка ⚙ открывает настройки, там же можно выйти и стереть данные.

> Если в OwenCloud включено **SMS-подтверждение записи**, кнопки RESET не сработают (приложение так и напишет). Отключите подтверждение в настройках компании OwenCloud.

## 3. На рабочий стол

### iPhone — иконка приложения
Safari → открыть сайт → кнопка «Поделиться» → **На экран «Домой»**.

### iPhone — виджет с температурой и кнопками (Scriptable)
1. Установите **Scriptable** из App Store (бесплатно).
2. В Scriptable нажмите **+**, вставьте содержимое `scriptable/Kotel.js`, назовите скрипт **Kotel**.
3. Запустите его один раз (▶). Он спросит email и пароль и найдёт параметры.
4. Рабочий стол → долгое нажатие → **+** → Scriptable → **средний** виджет → нажмите на виджет → Script: **Kotel**.
5. (Необязательно) впишите адрес сайта в `SITE_URL` в начале скрипта. Тогда нажатие на температуру будет открывать сайт.

Средний виджет: температура + кнопки RESET 1 / RESET 0. Нажатие на кнопку на секунду открывает Scriptable,
спрашивает подтверждение, отправляет команду и показывает уведомление. Совсем «тихо» нажимать кнопки в виджете
iOS сторонним приложениям не позволяет. Температуру iOS обновляет сама, обычно раз в 5–15 минут.

### Android — иконка приложения
Chrome → открыть сайт → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
Долгое нажатие на иконку «Котёл» показывает ярлыки **RESET 1** и **RESET 0**: их можно вытащить на рабочий стол
отдельными кнопками. Нажатие откроет приложение и попросит подтвердить запись.

### Android — виджет (наше приложение, рекомендуется)
Один виджет: температура + кнопки RESET 1 / RESET 0, работают прямо с рабочего стола.

В Android-приложении также есть плашка **Умный дом Яндекса** для датчиков из «Дома с Алисой». [Настройка Яндекс OAuth, подключение датчиков и сборка APK](YANDEX_SMART_HOME.md)

1. Скачайте APK: <https://github.com/Ix1ax/owencloud-pwa-widjet/releases/latest/download/kotel.apk>
   (собирается автоматически GitHub Actions из папки `android-app/` при каждом изменении).
2. Откройте файл → разрешите установку из этого источника → **Установить**.
3. Откройте «Котёл», войдите в OwenCloud → **Добавить виджет на рабочий стол**.

Нажатие на температуру обновляет её; сам виджет обновляется раз в 30 минут.
Кнопки 1 / 0 показывают окошко подтверждения (отключается в приложении).

### Android — виджет через HTTP Shortcuts (альтернатива)
Сайт сам по себе на Android виджетом стать не может, поэтому виджет делается бесплатным приложением
**HTTP Shortcuts** (Google Play / F-Droid). Код — в `android/http-shortcuts.js`.

1. Установите HTTP Shortcuts.
2. ⋮ → **Variables** → **+** → тип **Static**: создайте 4 переменные:
   `oc_login` (ваш email), `oc_password` (пароль), `kotel` (пусто), `kotel_cache` (пусто).
3. **+** → **Scripting** → название **Котёл обновить** → вставьте код из `android/http-shortcuts.js` → сохраните.
4. Ещё два таких же ярлыка: **RESET 1** и **RESET 0**, тот же код, но первая строка
   `const ACTION = 'reset1';` / `const ACTION = 'reset0';`.
5. Запустите «Котёл обновить» один раз в приложении (найдёт параметры P512/P527).
6. Рабочий стол → долгое нажатие → **Виджеты** → HTTP Shortcuts:
   - виджет **Variable** → переменная `kotel`, заголовок «Котёл», по нажатию — ярлык «Котёл обновить»;
   - два виджета **Shortcut** → «RESET 1» и «RESET 0».

Нажатие на температуру обновляет её, кнопки RESET спрашивают подтверждение и отправляют команду.
Если в настройках ярлыка «Котёл обновить» есть повтор по расписанию — включите (например, раз в 15 минут).

## Проверка на компьютере

```bash
python3 -m http.server 8765
```

Затем откройте <http://localhost:8765>.
